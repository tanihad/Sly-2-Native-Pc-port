## Findings / traps
- PowerShell 5.1 wraps native stderr at the console width when redirected with 2>: use cmd /c for traces.
- gs_replay profiles must use `--modern --aspect 16:9` to match in-game sample counts (4:3 field targets are ~2.7x smaller).
- Hybrid mode has no R2H_FRAME hint (frame data in the slot): per-frame flags must also be set from R2H_RUN.
- Pixel-shader atomics loops: helper pixels' atomics do nothing -> a CAS loop never ends for them (SV_Coverage == 0).
- A CAS loop on the colour word was slower than the ROV under heavy overlap; a counter texture + resolve is not.
- Full-screen passes at 3x 16:9 (2048x1344 samples, 11 MB per target) cost >= ~0.08 ms each (memory bound): only fusing
  passes saves more.
- The sandbox refuses Remove-Item on paths built from variables inside some commands; set env vars to $null instead.
