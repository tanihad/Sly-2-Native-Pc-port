  rotated into object space (0x3BA8 = inverse of the world 3x3), normalised, x 1/127, transposed into [21..24];
  [25..28] = colour_i * z_i * 2; [29] = 2 * sum colour_i * y_i; [30] = -y_i / z_i.
- 0x1050 per vertex: d = dirs^T n (n = itof0 of the V4-8 normal), f = d + d^3, f = min(f, [30]); C = sum [25+i] * f_i

  in place (x/w), 0x0500 edges {4 indices: opposite a, edge v0, edge v1, opposite b}: any vertex outside |.| <= 1 ->
