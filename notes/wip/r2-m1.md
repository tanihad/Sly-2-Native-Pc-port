## Findings (VU1 376110651 prelit path; addresses are VU byte addresses)
- VIF1 BASE 0x32, OFST 0x1E7 (f_157FA0 0x1582D4): buffers 0x032 / 0x219, 0x24B - TOP = the other buffer.
- Mesh batch = header (VU 9 fog params, 0xA..0x14 descriptors V4-16, 0x15 / 0x1E 9-qw material packets) + vertex
  streams (STCYCL 4/1: +0 UV V2-16 signed 4.12, +1 colour A V4-5 + S-8 alpha (STMASK 3F3F3F3F: w only), +2 colour B,
  +3 position V4-32, w = flag float ~2^23 + m (m bits 4..11 = fog base F, bit 15 = ADC, bits 12..14 = 0b111 so +0x1000
  /+0x2000/+0x4000 carry into ADC)), then `MSCAL 0; MSCAL 2E20|2E68|2EB0` (first sub-batch) and `MSCAL 2EE8` (second).
- Descriptors: [11].x flags (0x80 = no backface cull; 0x700 = billboard modes), [11].y copy end for 2E68;
  sub-batch 1: [13] = (in start, start+8, in end, NLOOP|0x8000), [14] = (pass A packet, pass B packet, 3rd packet or 0);
  sub-batch 2: [17], [18]. [10].x = continuation address of the buffer (pending kicks), [10].z = clip-needed.
- 2E20: 2D38 (run the other buffer's continuation), 0x0070 (M = W(VU 0..3 of buffer) x C(VU 2..5 absolute) -> 4..7),
  32B0 transform. 2E68: 0x0610 copies qw 0..9 (and 0x15..[11].y) from the other buffer. 2EB0: buffer header reused.
- Transform 06D0/0960: clip = x*M0 + y*M1 + z*M2 + M3; Q = 1/clip.w; STQ = (u/4096*Q, v/4096*Q, Q);
  XYZ = VU1.xyz + VU0.xyz * (x/w, y/w, z/w) as float BITS (VU0 = (33218888, 33218888, 4.252e9), VU1 = 0x50008000,
  0x50008000, 0x50400000: X = floor(0x8000 + 32440.3*x/w) (12.4), Z = mantissa>>4 = floor(0x40000 + 259522.6*z/w) < 2^19);
  W out = pos.w + VU9.y * min(clip.w, VU9.z)/clip.w (F = bits 4..11). Backface: compensated strip cross product, culled
  when sign == vi06 (0: cull, -1: none) -> ADC +0x4000. Fully off-screen -> +0x1000 (cull); crossing the guard band
  (x*7.93, y*18.1) -> +0x2000 and the clipper 2540 draws it as clipped fans later.
- Fade (VU 8.x < 1): colour A alpha and colour B RGB *= fade (trunc). VU 8.w != 0: alternate A+D qw (unsupported).
- Kick order: A1 (2E20 end), B1 (+3rd) at 2EE8, clip1; A2, B2, clip2 as continuations run by the NEXT routine's 2D38
  calls (or the class-end flush MSCAL 0x3AB0 = 3 x 2D38). So an entry's tail is drawn during the next entry: before a
  native run insert MSCAL 0x3AB0 + MSCAL 0 (flush, DBF parity kept).
- Material packet (9 qw): +0 vertex GIF tag (NLOOP filled by VU, PRE PRIM 0x7C tristrip IIP TME FGE ABE, REGS 4F12 =
  ST RGBAQ(+1 colour A) NOP XYZF2 / 41F2 = ST NOP RGBAQ(+2 colour B) XYZF2), +1 fan variant (clipper), +2 A+D tag (NLOOP
  6, PRE PRIM 0), +3..+8 TEX0_1 (CLD 1, CSM1 CT32 CLUT), TEX1_1 0x61 (bilinear, LCM K=0), CLAMP_1, TEST_1 (A 0x717EB:
  ATST GEQUAL 126 FB_ONLY, Z GREATER; B 0x51001: ATST NEVER FB_ONLY, Z GEQUAL), ALPHA_1 (A 0x44 (Cs-Cd)*As+Cd, B 0x48
  (Cs-0)*As+Cd), FOGCOL (B: 0).
- Frame constants at hook 0x158378: VU0 = sp+0x8160, VU1 = sp+0x8170, VU2..5 = sp+0x00, VU6..9 = sp+0x40 (f_157FA0).
- World entries (0x1D5808, not from the allocator 0x1CD998): form A c1 = whole packet (CNT: W identity to 0+tops,
  VU8 = (1,1,0,0)), c2 = 0; form B c1 = per-frame header (REFS 6 qw static + CNT VU8 = (fade,1,0,0)), c2 = mesh.
