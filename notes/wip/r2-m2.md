## Findings / traps
- HLSL: `pass` is a keyword. CRLF files: PowerShell multi-line .Replace fails silently - use the Edit tool.
- Bracket A/B harness: (1) a recording starting after its frame's R2H_FRAME: skip exact prims only for entries R2 took;
  (2) a bracket closes at the next entry's hook, after a class switch's packets: don't bracket the last native entry
  before a class switch / frame end.
- GPU-bound: per-segment cbuffer Map/UpdateSubresource and the arena Map blocked 2-50 ms -> fdata segment records +
  GPU frame fence.
- 1 Hz ~18 ms frame spike exists in reference mode too (not R2).
