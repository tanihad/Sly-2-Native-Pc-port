# r2-m8: modern renderer R8 (fully modern frames: free resolution, MSAA, motion vectors)

**Goal**: gameplay frames of modern mode render at any resolution (a render-scale percentage of the output, default 100%)
with MSAA off/2x/4x/8x (alpha-to-coverage for pass-A cut-outs), the HUD after the resolve, motion vectors; hybrid
frames (menus, loading, Binocucom...) stay on the exact grid; switching is seamless. D6 decided (2026-10-29): render
scale % + MSAA in Modern; "PS2 mode" = a preset button (Reference, integer grid, PS2 outlines / filters).

## Design ("MFT" = modern frame targets; render thread only, the frontend unchanged)
- **Per frame decision on the render thread** (gpu_exec.c has the whole frame's ops): a pre-scan (`mft_plan`) of the
  frame: modern frame (has GPU_FOP_R2 ops, X.mixed, fx), MFT enabled (settings), progressive + flicker off, the PRESENT
  shows one circuit of a display-family C32 target at DBX = DBY = 0, and every op touching display-family targets is
  one MFT can execute; else the grid path as today (unchanged code path: reference / gates identical).
- **MFT surfaces** twin the display-family targets (xtarget.mft): C32 -> MS colour RGBA8 at render res (+ the
  output-res single-sample "picture"), Z -> MS D32 at render res / single-sample at output res. GS -> MFT mapping:
  d3d = (gs + 0.5) * s (pixel centres symmetric: no grid shift at present), s = output (or render) pixels per GS pixel
  (x: picture width / 512, y: picture height / buffer rows).
- **Two phases**: A (3D, MS at render res) until the resolve point (the 2D class: R2 hint at the first class-5
  entry, moved back over the class-begin clears), then resolve (ResolveSubresource; render scale < 100%: + upscale to
  output res) and phase B (HUD, motion blur: single-sample at output res). Present shows B's picture 1:1.
- **Op support in MFT**: CLEAR; R2 segments (r2.hlsl R2_MFT perms: hardware Z gz/2^20, no SV_Depth, manual A2C via
  SV_Coverage for rule-0 alpha-test draws); FF triangles via vertices (like ps_ff_part: hardware-interpolated colour,
  fog, STQ, Z); sprites / line pixels (records evaluated at the native pixel: gs_frag with kx = ky = 1); thin lines;
  shadow pipeline (counter per sample with SV_Coverage + [earlydepthstencil], then a per-sample fused pass = cs_shfuse's
  function, ping-pong MS surface); NPOST (blur / flat) in phase B on the picture. Anything else -> grid frame.
- **Seamless switching**: per target "truth" flag (grid / MFT); materialize lazily: grid->MFT upsample at the start of
  an MFT frame for targets whose truth is the grid, MFT->grid downsample before a grid frame uses them.
- **Motion vectors**: camera reprojection from depth (full-screen, prev / cur screen models + clip matrices) + object
  velocity for moving R2 entries (prev W x C per entry keyed by header address). Not consumed yet (base for TAA/FSR).
