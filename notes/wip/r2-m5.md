## Done
- Hybrid check: `PS2_R2_ALT=<vblank>` (r2_capture.c: hybrid and all-exact frames alternate), `PS2_DUMP_TO`
  (ps2_runtime.c), scripts/r2_hcheck.ps1 + r2_hcheck.py (alternating pixels: i ~ i+2, i+1 differs from both; gate worst
  triple <= 0.2% and no 16x16 blob), in scripts/r2_sweep.ps1 as check `hc` (`-Checks ab,hc`).
- Root cause of the tree bug: **stale mesh decodes**. The game rewrites mesh DMA in place while a level streams in
  (ep1 hub: ~45 chains per run, at the load after START and up to ~400 frames into the hub); the cache's 32-byte
  fingerprint did not change, so the decode of the earlier content (another mesh's triangles, its textures) was used
  for the rest of the level. Intermittent (depends on load timing): ~half the runs. Fix: r2_src (r2_mesh.c) keeps a copy
  of every byte a chain read (tags + data ranges); mesh_for / outline_for compare it on every use (memcmp, capture
  0.33 -> 0.29 ms/frame: noise). Failed decodes are re-hashed every 2 s and decoded again when they changed.
  `PS2_R2_VERIFY=1` logs stale meshes. Stats: "stale n".
- Outline chains dropped in hybrid now owe their VIF1 DBF flips (3 MSCALs per batch: odd counts): MSCAL 0 with the
  R2H_OUTLINE hint (not the cause of the bug, but keeps an all-exact frame's parity).
