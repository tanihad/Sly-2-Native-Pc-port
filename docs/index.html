Job 03

The plan

Four steps, no lock-picking required. The launcher does the heavy lifting.

  1. Grab the launcher

    Download Sly2-Setup.exe and start it. It needs no administrator rights.

  2. Hand over the disc

    Drop the .iso image of your own Sly 2 disc on the window. It is checked on the spot.

  3. Let the gang work

    Setup fetches free build tools (about 220 MB) and builds the game on your PC. That takes from a few minutes to about twenty.

  4. Hit Play

    Press the big gold PLAY button. From now on the launcher starts the game and offers updates by itself.

Job 05

Before you pull the job

The questions an inspector would ask.

Is the game included in the download?

No. The download contains only the launcher and this project's own code. The game itself comes from your own disc: the launcher reads it and builds the PC version on your computer. Without your own copy of Sly 2 there is nothing to play.

Which version of the game do I need?

The USA release of Sly 2: Band of Thieves (SCUS-97316) as an unmodified .iso image. European (PAL) and other discs are not supported yet, and .bin/.cue, .chd or .cso images have to be converted to .iso first. The launcher tells you right away if a file can't be used, and why.

Is this an emulator?

No. An emulator imitates a whole console while the game runs. Here the game's code is translated once, ahead of time, into a native Windows program, and the console's graphics, sound and input are replaced by their PC equivalents.

Windows says "Windows protected your PC". Why?

The setup program is not signed with a paid certificate, so Windows SmartScreen does not know it. Click More info, then Run anyway. The source code is public, and every release lists SHA-256 checksums so you can verify your download.

Will updates keep my saves?

Yes. Saves and settings live in their own folder and survive updates and repairs. The launcher can even switch back to the previous version.

How do I remove it?

Windows Settings > Apps > "Sly 2: Band of Thieves (PC port)", or the Uninstall button in the launcher. It asks before it deletes your saves.

Does it cost anything?

No. The port is a free fan project and its source code is public on GitHub.
