# orig/

Put the files dumped from **your own** Sly 2 disc here. Nothing in this folder is committed.

Needed first:

- The main executable from the disc root, named after the disc's serial number, e.g. `SCUS_xxx.xx`
  (North America) or `SCES_xxx.xx` (Europe). Copy it here unchanged.

Later (for asset/format work):

- The rest of the disc's files, copied with the same folder structure.

Write down which region/version you dumped in `notes/progress.md`. Decomp projects target one
exact build, and other versions will not match.
