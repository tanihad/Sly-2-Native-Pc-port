# GS recording corpus for the Direct3D 11 renderer (notes/d3d11-renderer.md 10.4, appendix B).
# Recordings are PS2_GS_RECORD streams (runtime/gs_record.c), made with the software renderer from
# the user's own disc; they are never committed. Paths are relative to the corpus root
# (-CorpusRoot, else SLY2_GPU_CORPUS, else sly2-corpus next to the main checkout, else the old sly2-worktrees;
# scripts\gpu_corpus.ps1; the corpus tools skip with exit 0 when it is absent) and read in place. The corpus root must
# never be inside a build folder: the original recordings lived in worktrees' build\ folders and were lost to a disk
# cleanup (2026-11-12). Replay: scripts\gs_replay.ps1 -Rec <path> -Out <dir>.
# Census: scripts\gs_census.ps1 -Rec <path> -Full; tables: scripts\census_table.py ... --new "gpu-C-*".
# All 28 were re-recorded on 2026-11-12 (branch next/corpus, release build of main 336e78e) with
# scripts\gs_record_scene.ps1 (the "how" column; START is pressed at the title by the script unless -NoStart, pad
# tokens are relative to it) and its corpus settings (software renderer, 4:3 unless stated, the game's interlaced field
# offsets, own user folder), then copied to the corpus root under the paths below; each was checked with
# scripts\gs_corpus_verify.ps1 against the frames the live run dumped (verified: frames identical / compared).
#
# Columns (|-separated): path | scene | VBlanks (first-last) | MB | exercises | how | verified
